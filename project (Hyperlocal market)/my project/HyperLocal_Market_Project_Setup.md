## STEP 1 — Install Required Software (Windows)

Install the following in this exact order:

### 1.1 Git
- Download from: https://git-scm.com/download/win
- During install: choose **"Git from the command line and also from 3rd-party software"**
- Verify: open Command Prompt → `git --version`

### 1.2 Java Development Kit (JDK 17)
- Download from: https://adoptium.net (Temurin JDK 17 — LTS)
- Install to default path
- Add to environment variables:
  - Variable: `JAVA_HOME`
  - Value: `C:\Program Files\Eclipse Adoptium\jdk-17.x.x.x-hotspot`
- Verify: `java -version` → should show 17.x

### 1.3 Android Studio
- Download from: https://developer.android.com/studio
- During setup wizard, install:
  - Android SDK
  - Android SDK Platform (API Level 33 minimum, 34 recommended)
  - Android Virtual Device (AVD) — even though you use physical devices, SDK tools are still needed
- Set environment variables:
  - Variable: `ANDROID_HOME`
  - Value: `C:\Users\<YourUsername>\AppData\Local\Android\Sdk`
- Add to `PATH`:
  - `%ANDROID_HOME%\tools`
  - `%ANDROID_HOME%\tools\bin`
  - `%ANDROID_HOME%\platform-tools`
- Verify: `adb --version`

### 1.4 Flutter SDK
- Download from: https://docs.flutter.dev/get-started/install/windows
- Extract to: `C:\flutter` (IMPORTANT: do NOT put in `C:\Program Files` — permission errors)
- Add to `PATH`: `C:\flutter\bin`
- Verify: `flutter --version` → should show Flutter 3.x
- Run: `flutter doctor` → fix all ❌ items before proceeding

### 1.5 VS Code
- Download from: https://code.visualstudio.com
- Install the following extensions (Ctrl+Shift+X):
  - `Flutter` (by Dart Code)
  - `Dart` (by Dart Code)
  - `Firebase Explorer` (by toba)
  - `GitLens` (by GitKraken)
  - `Error Lens` (by Alexander)
  - `Pubspec Assist` (by Jeroen Meijer)
  - `bloc` (by Felix Angelov) — useful even with Riverpod
  - `Awesome Flutter Snippets`

### 1.6 Node.js (required for Firebase CLI)
- Download from: https://nodejs.org (LTS version)
- Verify: `node --version` and `npm --version`

### 1.7 Firebase CLI
```bash
npm install -g firebase-tools
firebase --version
firebase login
```

### 1.8 FlutterFire CLI
```bash
dart pub global activate flutterfire_cli
```
Add to PATH: `C:\Users\<YourUsername>\AppData\Local\Pub\Cache\bin`

## STEP 5 — Firebase Setup

### 5.1 Create Firebase Project
1. Go to https://console.firebase.google.com
2. Click **"Add project"**
3. Name it: `hyperlocal-market`
4. Enable Google Analytics: **Yes**
5. Click **"Create project"**

### 5.2 Enable Firebase Services
In the Firebase Console sidebar, enable these one by one:

**Authentication:**
- Build → Authentication → Get started
- Sign-in method → Enable: Email/Password, Google

**Firestore Database:**
- Build → Firestore Database → Create database
- Start in **test mode** (you'll add rules later)
- Location: choose closest to your users

**Firebase Storage:**
- Build → Storage → Get started
- Start in test mode

**Cloud Messaging (FCM):**
- Already enabled by default with Firebase project

### 5.3 Connect Flutter to Firebase
```bash
# In your project root
flutterfire configure --project=hyperlocal-market
```
Select: Android + Web when prompted.
This auto-generates `lib/firebase_options.dart`.

### 5.4 Android — Add google-services.json
- Firebase Console → Project Settings → Your apps → Android
- Download `google-services.json`
- Place it in: `android/app/google-services.json`

### 5.5 Update android/build.gradle (project level)
```groovy
buildscript {
    dependencies {
        classpath 'com.google.gms:google-services:4.4.2'
    }
}
```

### 5.6 Update android/app/build.gradle (app level)
```groovy

    id 'com.android.application'

    compileSdkVersion 34

        targetSdkVersion 34

    }

```

### 5.7 Firestore Security Rules
In Firebase Console → Firestore → Rules:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users can read/write their own data
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    // Shops are readable by all authenticated users
    match /shops/{shopId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'shop_owner';
    }
    // Orders
    match /orders/{orderId} {
      allow read: if request.auth != null &&
        (resource.data.customerId == request.auth.uid ||
         resource.data.shopOwnerId == request.auth.uid);
      allow create: if request.auth != null;
      allow update: if request.auth != null;
    }
    // Admin only
    match /admin/{document=**} {
      allow read, write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
  }
}
```

```dart
          seedColor: const Color(0xFF2E7D32), // Green - local/fresh feel

    );

}
```

## 📊 Firestore Data Structure

```
/users/{userId}
  - uid: string
  - email: string
  - name: string
  - role: 'customer' | 'shop_owner' | 'admin'
  - fcmToken: string
  - createdAt: timestamp

/shops/{shopId}
  - id: string
  - ownerId: string (ref to users)
  - name: string
  - description: string
  - category: string
  - latitude: number
  - longitude: number
  - address: string
  - phone: string
  - isOpen: boolean
  - rating: number
  - imageUrl: string
  - createdAt: timestamp

/shops/{shopId}/products/{productId}
  - id: string
  - name: string
  - description: string
  - price: number
  - imageUrl: string
  - inStock: boolean
  - category: string

/orders/{orderId}
  - id: string
  - customerId: string (ref to users)
  - shopId: string (ref to shops)
  - shopOwnerId: string
  - items: array
    - productId: string
    - productName: string
    - quantity: number
    - price: number
  - totalAmount: number
  - status: 'pending' | 'confirmed' | 'preparing' | 'ready' | 'delivered' | 'cancelled'
  - paymentMethod: 'cash_on_delivery'
  - customerLocation: geopoint
  - createdAt: timestamp
  - updatedAt: timestamp

/notifications/{notificationId}
  - userId: string
  - title: string
  - body: string
  - type: 'order_update' | 'new_order' | 'promotion'
  - isRead: boolean
  - createdAt: timestamp
```
